## LAB 05

In Lab 05, we studied advanced decision-making concepts in C programming. The main topics covered in this lab were **Nested If** and **Nested Switch** statements.

### Topics Covered
- Nested If Statements
- Nested Switch Statements
- Using multiple conditions in a program
- Making decisions using nested structures

### Lab Tasks
During the lab, we solved different programming tasks based on nested if and nested switch statements. These tasks helped us understand how multiple conditions and decisions can be combined to solve programming problems.

### Learning Outcome
After completing Lab 05, we learned how to use nested if and nested switch statements effectively in C programs and how to apply them to solve different programming problems.
